# Прототип A2-4CCH
**Allocator for Column Chromatography v2**

## Назначение
* Решение проблемы небольшой вместимости прошлой версии устройства
* Повышение надёжности

## Статус
В процессе разработки.

## Конструкция
* XY стол на винтовой передаче.
* Привод - JGA25-370 DC gear motor.
* Управление на плате STM32G474CEU6 от WeAct.
